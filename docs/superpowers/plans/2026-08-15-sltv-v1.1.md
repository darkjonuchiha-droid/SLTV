## F1 — Runtime channels (LSL only)
Owner adds/removes channels in-world without editing the notecard.
- Storage: LinksetData `sltv.xchan` = JSON array `[{ "n":…, "u":… }, …]`,
  appended to the notecard channels at config EOF (MAX_CHANNELS still caps).
- Owner menu gains **Add Ch** → `llTextBox`: enter `Name|https://url` to add,
  or `del Name` to remove a runtime channel (explained in the textbox prompt).
- Validation identical to notecard parsing (https only). Persisted; survives
  resets. No broadcast needed on add (list isn't in the fragment); switching
  to the new channel broadcasts as usual.

## F2 — First-visit guide (web only, TDD)
One-time on-screen setup card per viewer, replacing chat-spam guidance.
- `buildDom` adds a `#guide` overlay: sound (click once), volume (viewer media
  slider). Shown when `localStorage['sltv.guided'] !== '1'` (try/catch — CEF
  may block storage). "Got it" button sets the flag; auto-hide after 30 s.
- Overlay container `pointer-events:none`, card `auto` — must not block the
  unmute click. Above the shield.
- Tests: shown fresh / hidden when flagged / dismiss sets flag + hides.

## F3 — "Open in Browser" (LSL only)
Menu button **Open Web** (owner + guests) → `llLoadURL` with the CURRENT
channel's room URL. One click from in-world to the user's real logged-in
browser (the 8exy pattern; solves admin jumps without prim logins).

## F4 — Remote UNLOCK button (texture + both scripts)
- Texture: MENU row (y 736-920 / t 0.10-0.28) splits into **MENU** (left) and
  **LOCK** (right). Regenerate `assets/remote-texture.png` via the canvas
  generator; update `tools/remote-texture.html` to match.
- Remote `buttonAt`: that row returns `menu` (s<0.5) or `lockt`.
- TV `btn` dispatch: `lockt` → owner only (guests get a denial message), same
  feedback chat as the menu Unlock/Lock.
- Jon action: re-upload texture (L$10), re-apply to the remote face.
